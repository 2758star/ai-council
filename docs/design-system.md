## Visual Direction

- Default mode: restrained Memphis accents, geometric highlights, bright but not childish.
- Dark mode: focused dark interface for long study sessions and deep work.
- Layout: left navigation, top command bar, main canvas, optional context rail.

## Token Intent

- Typography: `Space Grotesk` for headings, `IBM Plex Sans` for body.
- Radius: large, soft corners for a desktop software feel.
- Motion: quick, minimal transitions with immediate hover response.
- Accent usage: only on hero areas, stat cards, and high-signal badges.
