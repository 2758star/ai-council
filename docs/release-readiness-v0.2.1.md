# Personal Secretary App 可交付清单（v0.2.1）

更新时间：2026-04-10

## 1. 当前可用范围（已完成）

- 本地桌面壳：Tauri 2 + React + TypeScript + SQLite
- 任务系统：年/月/周/日/看板、冲突检测、延期原因、周期任务、完成复盘标签
- 申请管理：项目与材料分层、官网变化联动、项目风险可视
- 资料库：本地扫描、导入流水、批量标签/关联、多格式预览、降级预览提示
- 通知中心：优先级、聚合、筛选、稍后提醒、转任务、批量动作
- 飞书链路：入站日志、去重、失败回执、手动重试、后台重试循环
- 晨间/晚间简报：手动与定时生成、建议一键应用、与任务/通知联动
- Web Capture & Watch：抓取、监控、diff、通知、转任务、预设包（申请/学习）
- AI 助手：内部工具调用、draft-write 默认、权限可视、策略审计、额度管理

## 2. 本轮新增稳定性增强（已完成）

- Dashboard 收口为只读指挥台，执行动作统一分流到对应模块。
- 飞书发送支持单次多次退避重试；后台失败重试支持配置。
- 通知可自动整理为建议任务（可开关）。
- 资料库搜索增强：
  - 多关键词
  - 全字段检索（标题/路径/分类/标签/摘要/类型）
  - 匹配模式切换（全部关键词 / 任一关键词）
  - 结果加权排序
- AI 审批链增强：
  - 权限审计日志
  - 全局 commit-write 安全闸（默认关闭）

## 3. 使用前自检（推荐每次更新后执行）

在项目根目录运行：

```bash
npm run selfcheck
```

该命令会依次执行：

1. TypeScript 类型检查
2. Rust 后端编译检查
3. 前端生产构建

全部通过后再进行 `npm run tauri:dev` 日常使用。

## 4. 快速回归测试清单（5-10 分钟）

1. 打开应用后无数据库字段报错（尤其 `time_start` / `dedupe_key`）。
2. 任务页可新增、延期、完成、删除，且日历与卡片同步。
3. 设置页飞书测试消息可发送；失败消息可手动重试。
4. Dashboard 可正常跳转 Today/Week/Calendar/Board。
5. 资料库搜索输入 2-3 个关键词可返回稳定结果；不支持预览格式会显示降级说明。
6. AI 页默认 `draft-write`，`commit-write` 在未开启全局开关时不可执行。

## 5. 仍建议后补（不影响当前可用）

- 飞书在“设备关机场景”的完整云端常驻补偿（本地版无法跨关机监听）。
- 资料库 OCR / 语义向量索引（当前为规则检索，稳定但不语义化）。
- AI commit-write 的“回滚事务 + 审批工单”企业级链路。
