# P2 收口状态（v0.2.4）

更新时间：2026-04-11

## 本轮完成

1. 资料库检索增强（FTS）
- 新增 `files_fts`（FTS5）迁移与自动重建。
- `scan_library` 后自动重建索引，避免新导入文件搜不到。
- `upsert_file_record`、`batch_set_file_tags` 自动同步 FTS 条目。
- `list_files` 改为优先 FTS，异常或不支持时自动回退旧打分搜索。

2. Daily Log 学习更新建议
- `Journal` 页新增 `Daily Log 建议区`：显示今日学习资源更新数量、未处理数量与快捷动作。
- 修复摘要区“今日学习资源更新建议”计数逻辑。
- 晨间/晚间简报接入学习更新统计，并在晚间生成可执行建议（可一键转任务）。

3. 项目页 Official Watchers 收口
- 项目总览卡监控状态从字符串升级为结构化状态：
  - `status`、`active/total`、`changed`、`missingLinks`。
- 新增 `补链/监控` 快捷动作，直达项目详情 `Official Watchers` 并自动预填链接。
- 模板区新增缺链清单与生成回执细化：
  - 创建项、重复跳过项、缺链项分开显示。
- 修复“补齐缺失模板”时序问题：
  - 生成动作使用同一份补齐后的草稿，避免偶发用旧 state。

4. 详情页与总览状态一致性
- 在 watcher 相关动作后统一双刷新：
  - `toggle / delete / 标记变化处理 / 变化转任务` 后同步刷新详情与总览。
- watcher 卡片新增可解释信息：
  - 待处理变化数、最近变化摘要、失败原因。
- 新增单项 `检查一次` 按钮，便于现场排错。

## 目前可直接验收的关键路径

1. 项目总览点击 `补链/监控` -> 模板区查看缺链清单 -> 一键补齐并生成。
2. 生成 watcher 后在详情页单项 `检查一次`，确认状态与摘要更新。
3. 处理变化（转任务/标记已处理）后，返回总览卡确认 `changed` 与 `status` 即时同步。
4. 资料库搜索输入关键词，确认新导入与标签更新文件可被检索到。
5. 生成晨间/晚间简报，确认包含“学习资源更新”统计与建议。
